# Character prompts

Generate each cat alone first (model sheet), then the expressions starting from the approved
model sheet as reference image ("smart reference" in Fotor). Keep the description text identical
every time: it is copied from the `Look` section of each sheet in `bible/characters/`.

## Model sheet template (status: draft)

```
character model sheet of <LOOK>, three views side by side: front, three-quarter, side, full body,
neutral pose, plain warm beige background, <STYLE BLOCK>
```

## Single portrait in the armchair (status: draft)

```
<LOOK>, sitting in a soft deep brown leather armchair in a warm tavern, medium shot, looking at
the camera, <STYLE BLOCK>
```

## Expressions (use the approved model sheet as reference) (status: draft)

One image per expression: `talking`, `laughing`, `rolling eyes`, `outraged`, `listening`,
`surprised`, `moved` (for Giovedì buone notizie).

```
same character as the reference image, <EXPRESSION> expression, sitting in a soft deep brown
leather armchair, medium close-up, <STYLE BLOCK>
```
