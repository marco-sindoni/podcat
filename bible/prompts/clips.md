# Clip prompts (CapCut AI video, image to video)

Start every clip from an approved reference image. Keep clips 4–5 s, camera mostly still, so they
can be reused and cut together. Mute the clip audio: voices come from the fixed CapCut voices.

## Library clip template (status: draft)

```
the cat in the image <ACTION>, subtle natural movement, mouth moving as if talking casually,
static camera, cozy warm tavern light, soft 3D cartoon animation, smooth motion
```

Actions to test, one clip each, for every cat:

| Action | Text for `<ACTION>` |
| --- | --- |
| talking | talks animatedly, small paw gestures |
| listening | listens, nods slowly, ears twitching |
| laughing | laughs, shoulders shaking |
| eye roll | rolls its eyes and sighs |
| outraged | jumps up indignantly (Fuzz only) |
| dozing | dozes and wakes up suddenly (Feedback only) |
| sipping | takes a long sip from a mug (Flanella only) |

## Wide establishing clip (status: draft)

```
slow gentle push-in on the cozy tavern with the four cats in their armchairs, fire crackling,
string lights flickering softly, static characters with subtle breathing, soft 3D cartoon animation
```
