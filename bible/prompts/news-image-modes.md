# News image templates (one per staging mode)

Every episode has one image made for its story. Rules: no realistic faces of real people, no logos
or brand names, no photos copied from news outlets, same style as the show. Two consecutive videos
never use the same mode.

## Mode A: the tavern TV (status: draft)

Generate the image alone, then place it on the CRT screen in CapCut.

```
illustration of <STORY SUBJECT, described without real people's faces>, simple bold composition
readable on a small screen, <STYLE BLOCK>
```

## Mode B: full-screen cut-in (status: draft)

2–3 s full screen with a slow zoom while a cat speaks off screen.

```
<STORY SUBJECT> as a funny exaggerated scene, centered subject, vertical 9:16, <STYLE BLOCK>
```

## Mode C: object in a cat's paws (status: draft)

```
<CAT LOOK> sitting in a brown leather armchair, holding up an old newspaper whose front page shows
an illustration of <STORY SUBJECT>, <EXPRESSION> expression, medium shot, <STYLE BLOCK>
```
