# Tracking file contract: scripts

Same rules as spec 001's `contracts/tracking-files.md` (UTF-8, front matter, unknown keys and
hand-written notes kept). Version files are written once; a new version is a new file.

Example version body (what Claude pastes into the Claude Doc), Italian:

```markdown
# Copione – venerdì 27 novembre 2026 · reel

**Notizia**: Hacker fanno impazzire i frigoriferi in Slovenia · tono comico · versione 1
**Parole**: 84 · **Durata stimata**: 31 s · **Immagine**: modo B (stacco a tutto schermo), scena 3

## Battute

1. **Flanella**: …
2. **Fuzz**: …
…

## Scene

| # | Inquadratura | Battute | Reazioni | Durata |
| --- | --- | --- | --- | --- |
| 1 | campo largo | 1 | Feedback sbadiglia | 4 s |

## Finali alternativi

**Finale 1** – Feedback: … / Flanella: …
**Finale 2** – Feedback: … / Flanella: …

## Note del capo autore

- …

Commenta le battute. Scrivi «finale 1» o «finale 2» per cambiare il finale, «approvato» per approvare.
```
